# Layers and lanes

Useful for a layered system, parallel tracks, or responsibility boundaries.

- Explain what lane order and boundaries mean. A layer is not a measured
  magnitude; do not imply quantity through arbitrary lane length.
- Preserve relationships and identities without padding lanes to match.
  Group a large structure when that improves orientation.
- Use short lane titles, but allow wrapping or responsive reflow rather
  than shrinking text. Label important connections between lanes.
- Details can remain inline or use accessible disclosure. A one-line-plus-
  hover layout is an option, not a requirement; a table may be appropriate.
