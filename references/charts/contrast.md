# Comparison and alternate paths

Useful for comparing entities, explanations, or paths under shared conditions.

- Use corresponding dimensions for a row-by-row table. For paths, identify
  the common starting point and distinguish the actual steps and outcomes.
- Preserve asymmetry: do not invent steps or attributes to make sides match.
  Distinguish specifications, observations, and qualitative judgments.
- Side-by-side HTML often handles substantial text better than an SVG;
  stack or reflow comparisons on narrow screens while retaining labels.
- A focus switch or branch selector is useful when it clarifies a real
  distinction. Support every displayed outcome with source evidence or an
  explicitly stated model, and keep the comparison understandable initially.
- Reduced motion removes transitions while keeping comparison controls
  functional. If dimming groups, check animation fill modes: child entrance
  animations may override opacity placed on the same element.
