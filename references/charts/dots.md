# Unit dots

Useful when discrete marks help a reader perceive counts or composition.

- State the unit: one dot represents one actual item or an explicitly
  aggregated quantity. Do not imply individual records from aggregate data.
- Preserve real totals. If rounding changes the total, explain it rather
  than adding phantom units to make a convenient grid.
- For multiple groups, keep unit size consistent and provide clear group
  labels. Density must still allow the intended comparison.
- When there are too many marks to read, aggregate transparently or choose
  another encoding. No fixed dot limit or entrance effect is required.
- This differs from a position-encoded [dot plot](scatter.md): dot count,
  rather than axis position, carries the quantity.
