# Threshold comparisons

Useful for a measured value against a meaningful boundary.

- Put values and thresholds on a compatible scale, with units and source
  anchors. Distinguish a source-defined boundary from a reader-chosen scenario.
- State the comparison rule and dependencies such as exchange rates or
  population assumptions. Verify a derived verdict and label its derivation.
- Do not fabricate an intermediate time series to fill a ruler or suggest
  precision beyond the inputs.
- If a reader can vary the threshold, use supported data or a stated model
  and show the changed condition with the result. No slider is necessary
  for a fixed comparison; see [interaction guidance](../interactions.md).
