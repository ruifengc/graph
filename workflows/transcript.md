# Videos, talks, and transcripts

Use with [base.md](base.md). Establish whether the available material is
video/audio, subtitles, a transcript, or an excerpt.

- Preserve timestamps and speaker attribution in working material, even
  when removing SRT syntax from prose. Use timestamp links or visible time
  ranges so a reader can return to key claims and demonstrations.
- Consolidate repetition and digressions without changing the speaker's
  position. Organize by questions, mechanisms, or stages as appropriate;
  the original speaking order is not mandatory.
- A transcript does not capture slides, gestures, experiments, or on-screen
  comparisons. Inspect relevant frames with available tools when a claim
  depends on them. If those frames are unavailable, explain the coverage
  limit and omit unsupported visual detail.
- Correct obvious transcription errors only when the context resolves them.
  Verify consequential names, numbers, and terminology against audio,
  frames, or another identified source when available. Flag unresolved
  ambiguity rather than guessing or silently rewriting it.
- Preserve conflicting statements when they matter. A verified correction
  can be explained as such; do not silently select the more convenient claim.
- Quote only wording supported by the material actually inspected. Mark a
  translation as a translation; use attributed paraphrase when wording is uncertain.
- Credit the title, speaker/channel, publication date when known, and URL.
  Note consequential omissions without reproducing unintelligible fragments.
