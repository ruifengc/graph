# Glyph · Dots

Countable units: one dot = one real thing (person, answer, dollar, unit).
The densest honest encoding for small data — turns percentages back into
people.

## When to use

- Shares / compositions with a small total (≤200 units): "a hundred
  people, four minds".
- Survey answers, cohort memberships, per-item tallies.
- When the input's aggregates can be decomposed into honest units
  (percentages summing to 100 → 100 dots).

## How to draw

- One dot = one unit; dot size fixed (r ~2), spacing consistent; grid or
  scattered within a bounded field.
- Decompose honestly: only real units. If rounding loses units (49.0 +
  27.4 + 13.9 + 5.0 + 3.2 → 98), state it in the caption — never add
  phantom units to make 100.
- Category color: gray ladder by importance; the story category on
  `--accent`.
- Caption states the unit ("one dot = one person in a hundred").

## Multi-group variant (groups of counted objects)

Counting comparison across groups: "5 groups × each dot is one real
object", groups stacked as rows with generous inter-group spacing
(grouped rows inside one field). Same contract as the single-field form — one dot = one
real thing, unit stated in the caption, group labels on the left.

## Rules

- Unit meaning in the caption, always.
- Count-up the headline number on enter.
- Density is the aesthetic: furniture (grid lines, rim ticks) is allowed;
  fake individual records are not.

## Pitfalls

- Inventing individual records from aggregates (never — only
  decomposable, honest units).
- Dots too dense to count (keep ≤200; else switch glyph).
