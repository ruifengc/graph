# Timelines and sequences

Useful for chronology or ordered stages. Sequence alone does not establish causality.

- Preserve event dates, order, and attribution. Keep video timestamps or
  original sections available as source anchors where relevant.
- If distance represents elapsed time, map dates proportionally. If the
  spacing represents order alone, label it as a sequence, not a time scale.
- Choose horizontal, vertical, or grouped layout for the event count and
  label lengths. A readable HTML sequence can work better than a wide SVG.
- Resolve clustered labels with alternating positions, grouping, or detail
  disclosure; do not silently discard a consequential event.
- Put essential event identity and context in the default view. Extra
  detail may live inline, in a disclosure panel, or in an accessible tooltip.
- Repeating a useful structure is fine. Alternating orientations, screen
  heights, cards, hover, or motion are not required.
